Getting started

What is Axiom

Axiom is a language for programming and for writing mathematics the way you would on paper. You type code in the editor; text results go to the output panel, and equations that depend on time become live signals with a time view and a frequency view.

f: R -> R, f = x^2 + 1;
print(f(3));
10

Live signals

Any assignment whose right-hand side uses the time variable t is sampled automatically and drawn in the Signals panel. Editing the equation re-renders it.

x = sin(2*pi*5*t);
y = 0.5*cos(2*pi*12*t) + x;

Signals can be called like functions and reused inside other signals:

x = sin(t);
print(x(pi/2));
1

How the time and frequency views work

The views are built so that changing the span never changes the numbers:

  • Fixed time grid. Samples sit on a fixed grid (step 1/256 s for spans up to 32 s, then 1/128, 1/64, …) so the same t gives the same sample at any span. Peaks and troughs of a tone read within 0.01–0.1% of the true value.
  • Fixed frequency grid. The spectrum is computed with a zero-padded FFT and shown on a fixed 1/32 Hz grid out to ±50 Hz. Each bin keeps the highest value inside it, so a narrow peak never falls between bins.
  • Two kinds of spectrum, chosen automatically. A persistent signal (still non-zero at the edges of the window, such as a tone) uses a Hann window and reads as amplitude: a tone of amplitude A shows A/2 at ±f. A transient signal (fades out inside the window, such as exp(-t)*u(t)) uses no window and reads as the transform |X(f)|. The legend says which one you are seeing.
  • Discrete-time signals are drawn as stems over integer n, with the DTFT in cycles per sample (−0.5 to 0.5).

Language basics

Statements and separators

End a statement with ; or start the next one on a new line. Two statements on the same line must be separated by ;.

a = 2; b = 3;
print(a * b)
6
x = 1 y = 2;
Error: Unexpected 'y' after a complete statement. Separate statements with ; or a new line (write 2*x or 2x for multiplication). (line 1, column 7)

Comments

# comment and // comment run to the end of the line.

print(1) # shown
// not shown
print(2)
1 2

Numbers

Integers, decimals (.5), scientific notation (1e3, 2.5e-2) and complex numbers with i.

print(1e3, 2.5e-2, 3 + 4*i)
1000 0.025 3 + 4i

Implicit multiplication

A number followed by a name or bracket, or a closing bracket followed by a bracket or name, multiplies. Same line only. A name followed by ( is always a call.

x = 4;
print(2pi, 3x, 2(3+1), (1+2)(3), 2x^2)
6.283185307179586 12 8 9 32

Constants

NameMeaning
piThe circle constant, approximately 3.14159. Use it for angles and periodic signals.
tauOne full turn in radians, equal to 2*pi (approximately 6.28318).
eEuler's number, approximately 2.71828; the base of the natural logarithm.
phiThe golden ratio, (1 + sqrt(5))/2, approximately 1.61803.
iThe imaginary unit, satisfying i^2 = -1.

omega

Constants such as pi, e and i cannot be reassigned.

Strings, booleans and null

Strings use single or double quotes. Comparisons give 1 (true) or 0 (false). null / none is the empty value.

print("hi", 3 > 2, null)
hi 1 null

Creating functions

Classic functions (function / fn)

Any number of parameters, a block body and return.

function area(w, h) { return w * h; }
print(area(3, 4));
12
function fact(n) {
  if (n <= 1) { return 1; }
  return n * fact(n - 1);
}
print(fact(5));
120

Typed math functions

name: Domain -> Range, name = expression. The input variable is always x. Inputs outside the domain and results outside the range are errors.

f: R -> R, f = x^2 + 1;
print(f(3));
10
g: [0, 1] -> R, g = x^2;
print(g(0.5));
0.25
g: [0, 1] -> R, g = x^2;
print(g(5));
Error: g() argument is outside its declared domain

Types: N Z Q R COMPLEX +R -R, intervals [a, b] (a, b) [a, b) (a, b], or the words open(a, b) closed(a, b) etc.

h: open(0, 1) -> R, h = 1/x;
print(h(0.5));
2

Signals (equations in t)

An equation in t is a continuous-time signal. It shows live, and can be called like a function.

x = exp(-t) * u(t);
print(x(1));
0.36787944117144233

Piecewise functions

{ value : condition, value : condition, value : otherwise }. If no branch applies and there is no otherwise, the result is NaN.

n = 3;
X = { 5 : n > 0, 10 : otherwise };
print(X);
5
n = -3;
print({ 5 : n > 0 });
NaN

Ternary form: cond ? a : b.

v = 2;
print(v > 1 ? "big" : "small");
big

Derived functions

diff(expr, x) returns a function you can call.

h = diff(x^3, x);
print(h(2));
12

Methods in classes

See the Classes demo under Example programs for fields, constructors, this and new.

Conditions and intervals

given: where a definition applies

expression given condition uses the value where the condition is true and gives NaN (undefined, not drawn as a value) elsewhere.

x = 4;
print(sqrt(x) given x >= 0);
x = -4;
print(sqrt(x) given x >= 0);
2 NaN
f: R -> R, f = 1/x given x != 0;
print(f(2));
0.5

where: local helper names

expression where name = value, ... defines helper names for that one expression. Later helpers can use earlier ones.

print(a*b + c where a = 2, b = a + 1, c = 4);
10
y = A*sin(2*pi*f0*t) where A = 2, f0 = 3;

Intervals: open, closed, exclusive, inclusive

FormMeaning
open(a, b) / exclusive(a, b)(a, b)
closed(a, b) / inclusive(a, b)[a, b]
openclosed(a, b)(a, b]
closedopen(a, b)[a, b)

Use them with in or as a typed-function domain or range.

print(5 in open(0, 5), 5 in closed(0, 5), 1 in openclosed(0, 1));
print(open(0, 1), closed(0, 1));
0 1 1 (0, 1) [0, 1]

forall and exists

print(forall(x, {1, 2, 3}, x > 0));
print(exists(x, {1, 2, 3}, x > 2));
print(exists(x, {1, 2, 3}, x > 5));
1 1 0

Control flow

if / else

x = 7;
if (x > 10) { print("big"); } else if (x > 5) { print("medium"); } else { print("small"); }
medium

while

j = 0;
while (j < 3) { print(j); j = j + 1; }
0 1 2

for

for (k = 0; k < 3; k++) { print(k * k); }
0 1 4
for v in {10, 20, 30} { print(v); }
10 20 30

switch

n = 2;
switch (n) { case 1: print("one"); break; case 2: print("two"); break; default: print("other"); }
two

break leaves a loop or case; continue skips to the next pass. Runaway loops and recursion are stopped with an error.

Sets and ranges

Sets and membership

A = {1, 2, 3}; B = {3, 4};
print(A union B, A intersect B);
print(2 in A);
{1, 2, 3, 4} {3} 1
print({1, 2, 3, ...});
{1, 2, 3, ...}

range

print(range(0:1, x, 4));
[0, 0.25, 0.5, 0.75, 1]

range(a:b, name, steps) gives steps + 1 evenly spaced samples including both ends. count({}) and sum({}) are 0.

Discrete-time signals

Defining x[n]

Write name[n] = expression. The signal is defined only for integer n, and x[k] or x(k) reads one sample. Assigning y = x preserves the discrete signal, so both forms work on y too. Any variable holding a discrete signal is drawn automatically as stems, with its DTFT.

h[n] = 0.5^n * u[n];
print(h[0], h[1], h[2], h[-1]);
1 0.5 0.25 0
h[n] = 0.5^n * u[n];
y[n] = cos(0.4*pi*n);
x[n] = n;
print(x[1.5]);
Error: x[n] is only defined for integer n (got 1.5)

Typed discrete signals

x[n]: Domain -> Range, x[n] = expression checks every sample.

h[n]: Z -> R, h[n] = 2*n;
print(h[4]);
8
h[n]: N -> R, h[n] = 2*n;
print(h[-1]);
Error: h[-1] is outside the declared domain

u[n], delta[n] and impulse

Square brackets give the discrete versions: u[n] is 1 for n ≥ 0; delta[n] and impulse(n) are the Kronecker delta (1 at n = 0).

x[n] = delta[n] + 2*delta[n-1] + 3*impulse(n-2);
print(x[0], x[1], x[2], x[3]);
1 2 3 0

Shifting with delay

delay(x, k) moves a signal right by k samples (use a whole number).

x[n] = u[n];
y = delay(x, 3);
print(y[2], y[3]);
0 1

Convolution with conv

conv(x, h) gives y[n] = Σ x[m]·h[n−m]. It sums m from −64 to 64 by default; pass a third argument to change that. Exact when both signals are zero outside the window.

x[n] = delta[n] + 2*delta[n-1];
h[n] = delta[n] + delta[n-1];
y = conv(x, h);
print(y[0], y[1], y[2]);
1 3 2

Calculus and transforms

diff

print(diff(x^2, x));
print(diff(x^2, x, at = 3));
function g(v) { return v^2; }
print(diff(g(x), x, at = 2));
2x 2x = 6 2x = 4

diff(..., at = a) returns text such as "2x = 6"; use formula(diff(...))[1] for the number. Unknown functions are an error.

integrate

integrate(expr, var, from, to) uses adaptive Gauss–Kronrod quadrature: wide ranges, endpoint singularities, jumps and infinite bounds.

print(integrate(sin(t), t, 0, 10000));
print(integrate(1/sqrt(t), t, 0, 1));
print(integrate(exp(-t^2), t, -inf, inf));
print(integrate(sin(t)/t, t, 0, 10));
1.952155368258766 1.999999989109418 1.7724538509055152 1.6583475942188746

If it cannot converge you get an error, never a wrong number:

print(integrate(1/t, t, 1, inf));
Error: integrate() did not converge. The integrand may diverge, oscillate too fast, or have a non-integrable singularity inside the bounds; try narrower bounds.

Fourier transform and series

FT(x(t), t, omega) uses the exp(-i*omega*t) convention. FS(x(t), t, period, n) gives the n-th complex coefficient.

x = exp(-t) * u(t);
print(FT(x(t), t, 1));
0.5 - 0.5i

The exact value is 1/(1+i) = 0.5 − 0.5i.

Signal sequence animation

Show complete signal states in order

animate(startSignal, signalSteps) takes the original signal and an ordered list of complete replacement signals. The app starts on startSignal; Next step switches directly to each item in signalSteps. It does not interpolate time or move a signal between positions, so a delay is shown as a later arrival.

startSignal = u(t);
signalSteps = [u(t - 1), u(t - 2), u(t - 3)];
x = animate(startSignal, signalSteps);

Use Show start to return to the initial signal. Previous step and Next step move through the list; the state you just left remains as a dashed shadow for comparison. The same controls are available in fullscreen.

Parameter names

ParameterMeaning
startSignalThe signal shown at the beginning of the sequence.
signalStepsA non-empty ordered array of full signal expressions. Each item is one discrete visual state.

Write arrays with square brackets. You can define the list in a named variable and pass that variable to animate.

Discrete-time example

For direct sample formulas, the discrete index is bound while each state is evaluated, so you can write u(n) or rect(n) inside the list. The list can also contain named discrete signals and delay results:

x[n] = animate(u(n), [rect(n)]);

startSignal[n] = u[n];
signalSteps = [delay(startSignal, 1), delay(startSignal, 3)];
y[n] = animate(startSignal, signalSteps);

Discrete states are shown as stems and can only change by whole samples.

Sequence behavior

Every list item is evaluated as a full signal. The labels show the current state number and which source it came from: startSignal or signalSteps[k]. A list must contain at least one signal expression.

Conventions and known limits

  • While integrating, 0 * infinity = 0. delta exactly on an integration bound counts half.
  • Numerical integration cannot see a feature much narrower than its sampling (a tiny pulse thousands of units away). Use bounds that enclose it.
  • diff of rect, tri, sinc, sawtooth, square, pulse is not symbolic yet and returns 0.
  • In the live view, samples that are not finite numbers are drawn as 0 (continuous) or skipped (discrete).
  • conv sums a finite window (default ±64 samples); infinite-support signals are truncated.
